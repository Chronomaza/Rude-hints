# Rude-hints
Ever found spore's hints annoying? Ever felt frustrated by unclear "this creation cannot be saved" messages? Do you like being called mean words while you play videogames? Then boy do I have the mod for you!
Changes:
- Anything the game considers a "hint" (text that fades in and then out again at the top of your screen. This includes editor warnings, the game gently reminding you how to play or that you're being attacked, etc)
- Yellow tutorial popups (with a few exceptions, will completely rude-ify the tutorials eventually)
This is my first mod for spore!
Not compatible with better save warnings, as this mod changes every error message and 'hint' popup that's not downright unused and technically serves the same purpose because of that. If you need to CLEARLY understand why your creation won't save I recommend using that mod instead
